# 🚗 STC89C52智能循迹小车

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

> 本项目是基于STC89C52单片机的智能循迹小车，通过红外传感器检测路面轨迹，实现自动循迹功能。

## 📖 项目概述

本项目制作以STC89C52为控制核心的智能循迹小车，用单片机产生PWM波，控制小车速度。利用红外光电传感器对路面黑色轨迹进行检测，并将路面检测信号反馈给单片机。单片机对采集到的信号予以分析判断，及时控制驱动电机以调整小车转向，从而使小车能够沿着黑色轨迹自动行驶，实现小车自动寻迹的目的。

## 🛠️ 硬件组成

- **核心控制器**: AT89C52单片机
- **传感器**: 红外光电传感器（左右各一个，用于轨迹检测）
- **执行机构**: 直流电机（带H桥驱动电路）
- **人机交互**:
  - 4个按键（前进、后退、左转、右转控制）
  - LED指示灯（流水灯效果）
  - 蜂鸣器（报警提示）
- **电源系统**: 电池供电

## 💻 软件功能

### 核心功能
- **自动循迹模式**: 通过红外传感器自动识别并跟踪黑色轨迹
- **手动控制模式**: 通过4个按键实现全方位手动控制
- **PWM速度控制**: 通过软件生成PWM波形控制电机速度
- **终点检测**: 当左右传感器同时检测到轨迹时，判定为终点并自动停止

### 辅助功能
- **LED流水灯**: 启动时显示视觉效果
- **蜂鸣器报警**: 多按键同时按下时触发报警
- **异常处理**: 轨迹丢失时的恢复机制

## 📂 代码结构

```
├── main.c          # 主程序文件，包含初始化和主循环
├── driver.c        # 驱动程序，包含电机控制、循迹算法等核心功能
├── driver.h        # 头文件，定义引脚映射和函数声明
└── README.md       # 项目说明文档
```

### 关键函数说明

**main.c:**
- `main()`: 程序入口，初始化并启动驱动
- `light()`: LED流水灯效果，用于启动视觉反馈

**driver.c:**
- `driver()`: 主驱动函数，处理按键输入和模式切换
- `ai()`: 自动循迹算法核心
- `forward()/back()/left()/right()/stop()`: 基本运动控制
- `end()`: 终点处理，执行停止动画
- `delay_ms()`: 精确延时函数，用于PWM生成

## ⚙️ 使用说明

### 操作方式
1. **自动模式**: 按下KEY1启动自动循迹功能
2. **手动模式**: 
   - KEY2: 后退
   - KEY3: 左转
   - KEY4: 右转
3. **异常状态**: 当两个以上按键同时按下时，蜂鸣器报警

### 硬件连接
- **P1口**: LED指示灯
- **P2口**: 电机驱动控制
- **P3口**: 按键输入和红外传感器
- **蜂鸣器**: 连接到指定控制引脚

2. 编译生成HEX文件
3. 通过编程器将程序烧录到STC89C52单片机
